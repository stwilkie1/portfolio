# portfolio

This repository contains a simple web app for keeping track of restaurants you want to visit. The application lets you store a restaurant name along with links to the menu and reservation page. Data is saved in your browser's local storage.

## Usage

Open `index.html` in a modern web browser. Fill out the form with the restaurant's name, menu URL, and reservation URL. The entry will appear in the list below the form. Each entry includes links to the menu and reservation pages and a button to remove the item from the list.

Because the data is saved in local storage, your list will persist as long as you use the same browser.
